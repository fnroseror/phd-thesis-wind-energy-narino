# 6. Candidate reference quality rules

A reference is acceptable if it meets at least one of these conditions:

```text
peer-reviewed journal article
official institutional source
recognized technical standard
highly cited foundational method
official dataset provider
reproducibility/open science source
```

A reference should be rejected if it is:

```text
not verifiable
not directly relevant
only loosely related
from an unreliable website
missing basic bibliographic data
duplicated unnecessarily
used only to inflate the reference list
```
