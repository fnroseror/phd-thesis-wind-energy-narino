En la implementación computacional, la variable auxiliar que aparecía
originalmente bajo la etiqueta FNRR dentro del modelo horario corresponde a un
objeto distinto del FNRR del Capítulo 4. Para evitar homonimia, se denomina índice
interno de estado TDQ (I_TDQ). Este índice resume condiciones internas de
confianza, variabilidad efectiva y memoria del estado; opera como predictor del
flujo TDQ-PIESS/KFAS y no se utiliza para modular energía.
