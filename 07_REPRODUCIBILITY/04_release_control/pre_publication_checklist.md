# Pre-publication checklist

- [ ] Replace every local repository folder with the latest delivered ZIP version.
- [ ] Extract all files from `00_ROOT_final.zip` directly into the repository root.
- [ ] Confirm no previous-version thesis PDF remains.
- [ ] Confirm whether the corrected thesis PDF may be released.
- [ ] Review the complete, unredacted evidence in `06_PRODUCTS`.
- [ ] Check that no credential, token, or private key is present.
- [ ] Check the Power BI link manually.
- [ ] Run `validate_repository.R`.
- [ ] Commit and push.
- [ ] Perform the clean-clone protocol.
- [ ] Archive the release commit hash and validation output.
